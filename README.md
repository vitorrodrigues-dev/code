# 🚀 Vitor.dev — Página de Apresentação

Uma landing page minimalista e responsiva desenvolvida com **HTML e CSS**, criada para ser utilizada como link de bio (Instagram, LinkedIn, etc).

## 🧠 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de criar uma **presença digital simples, moderna e profissional**, mesmo sem o uso de JavaScript.

A ideia é apresentar:

* Quem eu sou
* Meus conhecimentos atuais
* Links importantes

Tudo isso com um design **dark, minimalista e responsivo**.

---

## 🎯 Objetivo

Criar uma página leve e direta que funcione como um **cartão de visita digital**, especialmente para quem está iniciando na área de desenvolvimento.

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* Google Fonts (Inter)

---

## 💡 Funcionalidades

* Layout totalmente responsivo 📱
* Design minimalista (dark mode)
* Seção de apresentação pessoal
* Lista de habilidades (skills)
* Botões para redes profissionais
* Estrutura pronta para futuros projetos
